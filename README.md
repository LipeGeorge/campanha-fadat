# Campanha Fadat

Quero construir a landingpage para este projeto. A ideia, além de todas essas informações, é também ter uma pegada de jogo. Talvez com um botão de start no início.. O passo a passo se dará da seguinte forma (Os termos a seguir são meramentes ilustrativos):

Missão 01 - Criar Usuário ou Iniciar Missão ou outro nome que você achar melhor (Imagem)
Missão 02 - Escolha seu destino

Conforme o usuário responde, o sistema vai montando um perfil. No final da experiência, o comercial recebe muito mais do que um simples formulário, para que ao invés de ligar perguntando "qual curso você quer?", ela já inicia a conversa de forma personalizada.

Missão 03 - Desafios (Como na outra imagem)
Missão 04 - Desbloqueie seu futuro (Também em outra imagem)
Missão 05 - Boss Final (Também em outa imagem) 

No pdf tem uma ideia inicial de landingpage, tanto para desktop, como pra mobile.  A ideia é hospedar em um totem, então possivelmente seja melhor um designer mobile. A ideia do pdf tá bem poluída, então seja meio gamer mas também minimalista
